
# MyFinance

Sistema de controle financeiro pessoal e acompanhamento de investimentos, desenvolvido para ajudar jovens e iniciantes a organizar sua vida financeira.

## Sobre o projeto

O MyFinance é uma aplicação que permitirá acompanhar receitas, despesas, contas, investimentos e metas financeiras em uma interface simples e intuitiva.

O objetivo é tornar o acompanhamento financeiro mais acessível, sem exigir conhecimentos avançados sobre investimentos.

## Funcionalidades planejadas

- Cadastro e gerenciamento de contas.
- Registro de receitas e despesas.
- Controle de despesas recorrentes.
- Acompanhamento manual de investimentos.
- Registro de aplicações, resgates e rendimentos.
- Criação e acompanhamento de metas financeiras.
- Dashboard com gráficos e indicadores.
- Acompanhamento da evolução do patrimônio.

## Tecnologias
